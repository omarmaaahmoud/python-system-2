# نظام بيانات المستبعدين والمسجونين - مديرية التربية والتعليم بالإسكندرية
### Exclusions & Prisoners Data System - Alexandria Educational Directorate

تطبيق مكتبي متكامل فائق الأداء والسرعة مبني باستخدام **Python** و **PySide6 (Qt for Python)** و **SQLite Relational Database** مع دعم أصلي كامل لواجهة المستخدم باللغة العربية (RTL) واستيراد دفعي سريع لملفات الإكسيل متعددة الأوراق.

---

## 🌟 أبرز الميزات التقنية (Key Features)

1. **واجهة عربية فائقة السرعة وتصميم Dashboard مودرن:**
   - تصميم متناسق بألوان الأزرق الداكن والرمادي والنيلي المتطابقة مع المعايير الحكومية التنفيذية.
   - دعم مباشر لاتجاه الكتابة العربي (RTL).
   - بطاقات إحصائية (KPIs) فورية لحصر الموظفين، المستبعدين، والمحكومين.
   - 6 أزرار إجراءات سريعة لتسهيل الوصول المباشر لكافة أركان المنظومة.

2. **قاعدة بيانات علائقية SQLite متكاملة:**
   - تفعيل القيود والمفاتيح الأجنبية `PRAGMA foreign_keys = ON;`.
   - نمط `WAL (Write-Ahead Logging)` لتحقيق أقصى سرعة قراءة وكتابة متزامنة.
   - فهارس مخصصة على الرقم القومي، الاسم، والإدارات التعليمية وأنواع القضايا.

3. **استيراد دفعي ذكي لملفات Excel:**
   - التعرف التلقائي على أوراق العمل (سواء كانت مستبعدين أو مسجونين).
   - مطابقة ذكية لأسماء الأعمدة باللغة العربية والإنجليزية.
   - تنقية وتحويل الأرقام القومية والتواريخ بدون أي استثناءات أو توقف.
   - تنفيذ في خيط خلفي `QThread` مع شريط تقدم مباشر دون أي تجميد للواجهة.

4. **بحث متقدم وفوري:**
   - بحث حي عند كتابة كل حرف بالاسم أو الرقم القومي (14 رقم).
   - تصفية متقدمة حسب الإدارة التعليمية ونوع القضية والموقف الجنائي.

5. **تصدير وطباعة تقارير Excel:**
   - إمكانية تصدير أي جدول أو نتائج بحث مصفاة إلى ملف إكسيل بضغطة زر واحدة.

6. **كشف الأسماء المتشابهة والمكررة:**
   - خوارزمية فحص ومطابقة آلية للأسماء والأرقام القومية لمنع تكرار القيد وضمان سلامة السجلات.

7. **المسح الضوئي الذكي للمستندات (Smart OCR):**
   - استخراج وتعبئة بيانات المستبعدين والمسجونين مباشرة من صور القرارات والخطابات الورقية.

## 🚀 طريقة التشغيل (How to Run)

### 1. تثبيت الحزم المطلوبة:
```bash
pip install PySide6 pandas openpyxl
```

### 2. تشغيل التطبيق:
```bash
python main.py
```

### 3. تجربة الاستيراد الفوري:
يمكنك الضغط على زر **استيراد بيانات (Import Excel Sheet)** واختيار الملف التجريبي المرفق مع المشروع:
`sample_alex_education_data.xlsx`.
