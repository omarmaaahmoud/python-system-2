# 📁 هيكلية المشروع ومسؤوليات الملفات (Project Structure & File Responsibilities)
## التطبيق المكتبي الموحد — مديرية التربية والتعليم بالإسكندرية

يوضح هذا المستند التنظيم الهيكلي للمشروع، ومسؤولية كل ملف وحزمة برمجية، وتوضيح الفصل المعماري التام بين النظامين.

### 2. جدول الفصل المعماري والمسؤوليات بين النظامين

| وجه المقارنة | النظام الأول (المستبعدين والمسجونين) | النظام الثاني (تأمين المدارس وحراس الأمن) |
|---|---|---|
| **الهدف الوظيفي** | إدارة السجلات القضائية والأمنية للعاملين بالتعليم | حصر منشآت وتجهيزات الدفاع المدني وحراس الأمن بالمدارس |
| **قاعدة البيانات** | `data/exclusions_prisoners.db` | `data/school_security.db` |
| **مدير البيانات (DAL)** | `DatabaseManager` في `database.py` | `SchoolSecurityDatabaseManager` في `school_security/` |
| **حزمة الكود الرئيسية** | مجلد `ui/` الرئيسي | حزمة مستقلة بالكامل `school_security/` |
| **طريقة العرض في الجداول** | نماذج افتراضية `RecordTableModel` | نماذج افتراضية `SchoolTableModel` و `GuardTableModel` |
| **نقطة الدخول بالواجهة** | الفهرس 0 في `master_system_stack` بالنافذة الرئيسية | الفهرس 1 في `master_system_stack` بالنافذة الرئيسية |
| **محرك استيراد الإكسيل** | `ExcelImporter` في `excel_importer.py` | `SchoolSecurityExcelImporter` و `ImportWorker` |
| **سياسة الحفظ في التحديث** | مستثناة من الاستبدال عند النشر للقرص `E:` | مستثناة من الاستبدال عند النشر للقرص `E:` |
