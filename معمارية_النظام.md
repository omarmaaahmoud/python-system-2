```

|  +-----------------------------------------------------------------------------+  |
|  |                 الصفحات الأساسية الـ 6 (QStackedWidget)                     |  |

|  |  [2] سجلات المسجونين والقضايا (PrisonersView)                               |  |
|  |  [3] إدارة أنواع القضايا (ManageCaseTypesView)                               |  |
|  |  [4] البحث الشامل والمتقدم (AdvancedSearchView)                              |  |

|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  |                         نوافذ الإجراءات والعمليات                           |  |
|  |  * RecordDialog: تسجيل / تعديل بيانات موظف وقرار                           |  |
|  |  * ExcelImportDialog: استيراد كشوف الإكسيل مع المعالجة اللحظية             |  |
|  |  * SmartScanDialog: المسح الضوئي الذكي للمستندات والقرارات                 |  |
|  +-----------------------------------------------------------------------------+  |
+----------------------------------------+------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|               ⚡ طبقة النماذج الافتراضية (Qt Virtualized Table Models)             |
|                                                                                   |
|   ExcludedTableModel       PrisonerTableModel        AdvancedSearchTableModel     |
|       (مستبعدين)                (مسجونين)                   (بحث شامل)            |
|                                                                                   |
|   * تقنية التحميل والعرض عند الطلب (Virtual Scrolling)                            |
|   * استجابة فورية بدون أي تجميد للواجهة حتى مع عشرات الآلاف من الصفوف             |
+----------------------------------------+------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|              ⚙️ طبقة المعالجة والخدمات الخلفية (Services & Background)            |

+----------------------------------------+------------------------------------------+
                                         |
                                         v

|   * دالة المطابقة والبحث الذكي باللغة العربية: normalize_arabic()                 |
|   * استعلامات الفرز السريعة والمجمعة وإحصائيات لوحة التحكم                        |
+----------------------------------------+------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|                 📁 طبقة التخزين وقاعدة البيانات (Storage Layer)                   |

|   * وضع WAL (Write-Ahead Logging) لأقصى سرعة قراءة وكتابة متزامنة                 |

|   * الحذف التسلسلي الآمن ON DELETE CASCADE                                        |

## 🗄️ 2. المخطط العلائقي لقاعدة البيانات (Database ERD)

   +-------------------+              1 : N            +---------------------+
   |  Administrations  |------------------------------>|      Employees      |
   | (الإدارات التعليمية) |                               |     (بيانات الموظف)  |
   +-------------------+                               +---------------------+
                                                                  |
                                                                  | 1 : N
                                      +---------------------------+---------------------------+
                                      |                                                       |
                                      v                                                       v
                          +-----------------------+                               +-----------------------+
                          |    ExcludedRecords    |                               |    PrisonerRecords    |
                          | (قرارات الاستبعاد)    |                               |  (قضايا الحبس والأحكام)|

                                      ^                                                       ^
                                      | N : 1                                                 | N : 1
                                      +---------------------------+---------------------------+
                                                                  |
                                                       +--------------------+
                                                       |     CaseTypes      |
                                                       | (أنواع وتصنيف القضايا)|
                                                       +--------------------+
```
